# Challenge data

Official challenge archive:

- Source: picoCTF artifact storage
- URL: https://artifacts.picoctf.net/c_rhea/12/challenge.zip

The archive contains the challenge files required for `Verify`, including the checksum, decryption helper, and candidate artifacts.

The binary archive is not mirrored directly in this repository because redistribution rights for picoCTF challenge artifacts have not been verified. Use `fetch.sh` to retrieve the exact package from the official source instead of copying it from a third-party write-up repository.

```bash
cd data
./fetch.sh
```

After download, keep `challenge.zip` and extracted challenge files local unless redistribution permission is confirmed.
